# Clean Code Conventions                                                                  
                                                                                            
  - Files go in the folder that matches their concern (api routes in app/api/, components in
   components/).                          
  - No dead code, no console.logs left in.                                                  
  - Name things for what they are, not what they do (participants not handleData).          
  - Extract a helper only when logic is used in 2+ places.
  - No commented-out code.
